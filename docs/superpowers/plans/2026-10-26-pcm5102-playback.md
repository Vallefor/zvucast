**Goal:** На pi4 включённые jack и GY-PCM5102 оба видны в карте колонки, и звук идёт в узлы PipeWire этих карт, а не всегда в наушниковый jack.

**Architecture:** Имя ALSA-карты (`snd_rpi_hifiberry_dac`, `bcm2835 Headphones`) не является `node.name`. `pw-play --target` с таким именем не падает и молча линкуется в sink по умолчанию — сейчас это `alsa_output.platform-fe00b840.mailbox.stereo-fallback`. Живой узел ЦАП — `alsa_output.platform-soc_sound.stereo-fallback`. Слот выхода перестаёт быть одним алфавитным устройством: у каждого включённого выхода каналы 0 и 1 получают `l`/`r`, и на каждый живой узел поднимается свой `pw-play`. Пустой выбор по-прежнему берёт запасной sink. Имя, которого нет среди живых sink, запасным не подменяется.

**Tech Stack:** Rust, GStreamer DeviceMonitor, PipeWire (`pw-dump`, `pw-play`), существующий React-маппинг (`outputRows` уже показывает каждый канал со `stream` `l`/`r`).

## Global Constraints

- Слот захвата не менять. Первое по алфавиту невиртуальное устройство с включённым каналом `index <= 1`, иначе первое виртуальное. Канал 0 → `l`, канал 1 → `r`. Выключенный левый не становится правым. `capture_target` и `merge_inputs` ведут себя как сейчас.
- Виртуальный ключ (`zvucast`, `zvucast-*`) целью воспроизведения не бывает.
- Заглушки `capture` и `playback` устройством не являются.
- Строка ALSA (`plughw:`, `hw:`, … — `configured_pipewire_node` даёт `None`) по-прежнему только для бэкенда ALSA. Этот план её не «чинит» и не считает узлом PipeWire.

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub struct SinkNode {
    pub node_name: String,
    pub card_name: String,
}

pub fn sink_nodes_from_dump(json: &str) -> Vec<SinkNode> {
    let Ok(items) = serde_json::from_str::<Vec<serde_json::Value>>(json) else {
        return Vec::new();
    };
    let mut out = Vec::new();
    for item in items {
        let Some(props) = item.pointer("/info/props") else { continue };
        if props.get("media.class").and_then(|v| v.as_str()) != Some("Audio/Sink") {
            continue;
        }
        let Some(node_name) = props.get("node.name").and_then(|v| v.as_str()) else { continue };
        if node_name.is_empty() {
            continue;
        }
        let card_name = props
            .get("alsa.card_name")
            .and_then(|v| v.as_str())
            .unwrap_or("")
            .to_string();
        out.push(SinkNode { node_name: node_name.to_string(), card_name });
    }
    out
}

pub fn resolve_playback_key(key: &str, device_name: &str, sinks: &[SinkNode]) -> String {
    if sinks.iter().any(|s| s.node_name == key) {
        return key.to_string();
    }
    let mut matches: Vec<&SinkNode> = sinks
        .iter()
        .filter(|s| !s.card_name.is_empty() && (s.card_name == key || s.card_name == device_name))
        .collect();
    matches.sort_by(|a, b| {
        let rank = |n: &str| if n.contains("stereo-fallback") { 0 } else { 1 };
        rank(&a.node_name).cmp(&rank(&b.node_name)).then(a.node_name.cmp(&b.node_name))
    });
    matches.first().map(|s| s.node_name.clone()).unwrap_or_else(|| key.to_string())
}

pub fn live_sink_nodes() -> Option<Vec<SinkNode>> {
    let out = std::process::Command::new("timeout").args(["2", "pw-dump"]).output().ok()?;
    if !out.status.success() {
        return None;
    }
    let text = String::from_utf8(out.stdout).ok()?;
    if serde_json::from_str::<Vec<serde_json::Value>>(&text).is_err() {
        return None;
    }
    Some(sink_nodes_from_dump(&text))
}
```

`merge_outputs` копирует сборку `merge_inputs` (имя, enabled, prefs), затем вызывает новый `assign_playback_streams`, не `assign_stream`.
